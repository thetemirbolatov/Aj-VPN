# AJ VPN

AJ VPN — это лёгкий, быстрый и безопасный VPN-клиент для Android, созданный разработчиком Telegram-ботов Клаусом (@thetemirbolatov).

Приложение создано для тех, кто ценит простоту, скорость и минималистичный дизайн.

## Что вы получаете

- Высокая скорость: Быстрое соединение без задержек.
- Раздельное туннелирование: Выбирайте, какие приложения работают напрямую, а какие — через VPN.
- Минималистичный дизайн: Строгий чёрно-белый интерфейс с плавными анимациями.
- Без рекламы и трекеров: Только вы и интернет.
- Мультиязычность: Поддержка русского, карачаевского и английского языков.
- Простота: Одно нажатие для подключения.

## Платформы

- Android: Доступно (APK)
- iOS: В будущем (следите за обновлениями)

## Установка (Android)

1. Скачайте последний APK-файл из раздела Releases.
2. Разрешите установку из неизвестных источников в настройках телефона.
3. Установите приложение и подключитесь одним нажатием.
